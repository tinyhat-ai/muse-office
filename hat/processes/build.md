# How <project> runs — Build

Lead: Developer. Design: Designer.

## Steps

1. Plan — the chief of staff writes what "done" looks like, with the user.
2. Design — the Designer makes 3 options; the user picks (waiting on you).
3. Build — the Developer builds it on a preview link.
4. Check — the chief of staff checks it against the plan.
5. Your OK — the user looks at the preview (waiting on you).
6. Launch — the Developer puts it live and writes down how to change it.

## Done when

It is live and the how-to is in Notes.
