# Contributing to Muse Office

Before changing the UI, agent actions, hat instructions, or product behavior,
read [the Office product skill](.agents/skills/office-product-model/SKILL.md).
Use the relevant contracts in `spec/` and keep the corresponding `hat/` guidance
aligned. Preserve existing records and customizations.

The contributor skill guides work on this repository. Runtime skills in
`hat/skills/` teach the user's Muse; changing reference code alone does not
update an Office that Muse has already built.
